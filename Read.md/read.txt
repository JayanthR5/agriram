## 📖 Overview

AgriRam is an AI-powered smart agriculture platform designed to assist farmers with crop management, disease prediction, weather insights, and productivity improvements.

## Features

- Farmer Dashboard
- Crop Recommendation
- Disease Prediction
- Weather Integration
- Authentication
- Responsive UI

## Tech Stack

Frontend

- React.js
- Tailwind CSS

Backend

- Node.js
- Express.js

Database

- MongoDB

AI

- Python
- TensorFlow

## Architecture

```
React Frontend
      ↓
Express API
      ↓
MongoDB
      ↓
AI Prediction Engine
```

```
git clone

npm run dev
```
